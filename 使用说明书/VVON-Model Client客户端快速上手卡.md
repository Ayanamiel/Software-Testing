# VVON-Model 快速上手

## 首次使用（做一次就好）

### ① 安装

双击 `VVON-ModelSetup.exe`

- 弹蓝色警告 → 点「**更多信息**」→「**仍要运行**」（正常现象）
- 弹权限确认 → 点「**是**」

### ② 把身份文件发给画师

打开 `VModelClient` → 点「**导出请求**」→ 保存 → 把 `VVON-授权请求.vreq` 发给画师

> 这个文件不含私密信息，可放心发送

### ③ 等画师发回 `.vkit` 加密模型

---

## 每次使用

```
打开 VModelClient
      ↓
点「浏览...」选 .vkit 文件
      ↓
点「加载并挂载模型」
      ↓
等 VTS 自动启动（进度条不动是正常的）
      ↓
在 VTS 模型列表里加载模型
```

**用完点「⛔ 停止并卸载」**

---

## 三件必须知道的事

### 🔴 卸载会直接关掉 VTube Studio

不会给它保存的机会。**请先在 VTS 里保存好设置，再点卸载。**

### 🔴 换电脑 / 重装系统 = 模型全部失效

钥匙绑定这台电脑的这个 Windows 账户，**无法备份迁移**。

重装前先联系画师，装好后重新走一遍「导出请求 → 请画师重新发包」。

### 🔴 模型文件夹打不开是正常的

VTS 之外的任何程序都读不了模型内容 —— 这正是加密保护在起作用。

---

## 出问题先看这里

| 提示 | 怎么办 |
|---|---|
| 未检测到 VTube Studio | 先手动打开一次 VTS，再点加载 |
| 无法挂载到 VTS 模型目录 | 右键程序 →「以管理员身份运行」 |
| 同名模型目录已存在 | 去 VTS 模型文件夹删掉同名的那个 |
| 检测到逆向分析工具 | 关掉 RenderDoc / Cheat Engine 等再试 |
| Dokan 驱动未就绪 | 重启电脑 |
| 程序完整性校验失败 | 重新下载安装包完整安装 |
| 包的接收密钥与本机不匹配 | 这个包不是给你这台电脑的 |

## 其他

- **完全不联网**，没有账号、不需要激活
- 模型是临时装载，关掉就卸载，硬盘上不留明文
- 别单独移动 `.vkit` —— 旁边的 `.cfgs` 文件夹存着你在 VTS 里的设置，要一起带走

**需要帮助时请提供**：完整提示文字 + Windows 版本（`Win+R` 输 `winver`）+ 日志

日志位置（粘到文件管理器地址栏）：

```
%LOCALAPPDATA%\VVON\ModelClient\Logs
```

详细说明见《VVON-Model Client 使用说明》。
