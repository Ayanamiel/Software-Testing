# VVON-Model Client 使用说明

给购买了加密模型的买家。

---

## 这个软件是做什么的

画师把模型加密成一个 `.vkit` 文件发给你。这个软件负责把它**临时装载**给 VTube Studio 使用。

模型文件全程保持加密，**不会有解压出来的明文文件留在你硬盘上**。用完卸载，一切恢复原样。

---

## 一、首次使用（只需做一次）

### 第 1 步：安装

1. 双击 `VVON-ModelSetup.exe`
2. **会弹出蓝色警告窗**说"Windows 已保护你的电脑" → 点 **更多信息** → 点 **仍要运行**
3. 会弹权限确认框（要安装驱动组件）→ 点 **是**
4. 点安装按钮，等它跑完

装好后桌面出现 `VModelClient` 图标。

> **蓝色警告是正常的。** 因为这个软件用的是自签名证书，Windows 不认识，所以提示"未知发布者"。想核对身份的话，右键安装包 → 属性 → 数字签名，签名者应该是 `VVON Model Client`。

### 第 2 步：把你的"钥匙指纹"发给画师

打开软件，你会看到最上面一栏 **🔑 本机公钥指纹** 里有一串字母数字。

**这串东西就是你这台电脑的身份。**

点右边的 **导出请求** 按钮 → 选个地方保存（默认文件名 `VVON-授权请求.vreq`）→ 把这个文件发给画师。

> 这个文件里**只有公开信息，没有你的私密密钥**，可以放心发送。

### 第 3 步：等画师发回加密模型

画师用你的请求文件加密模型，会得到一个 `.vkit` 文件发给你。

**这个文件只有你能打开** —— 转发给别人，别人也用不了。

---

## 二、日常使用

### 加载模型

1. 打开 `VModelClient`
2. 点 **浏览...** 选择画师给你的 `.vkit` 文件
3. 点 **加载并挂载模型**
4. 等一会儿，VTube Studio 会自动启动
5. 在 VTS 的模型列表里找到该模型，点它加载

> **进度条会一直停在 0%，文字显示「正在处理...」** —— 这是正常的，进度只显示"开始"和"完成"两种状态。大模型可能要等十几秒。**别以为卡死了去强制关闭。**

### 用完之后

点 **⛔ 停止并卸载**。

> ⚠️ **重要：这会直接关闭 VTube Studio，不会给它保存的机会。**
>
> **请先在 VTS 里保存好你调整的设置，再点卸载。**
>
> 直接关闭本软件窗口也是一样的效果。

## 三、你会遇到的正常现象（不是故障）

### 打不开模型所在的文件夹

模型加载后，你会发现 VTS 的模型目录里那个文件夹**点不进去**，提示"拒绝访问"。

**这是正常的，也是这个软件的核心功能** —— 只有 VTube Studio 能读取模型内容，其他任何程序（包括文件资源管理器）都读不了。这样别人拿不到画师的模型文件。

### 别人的模型打不开

如果你拿到的 `.vkit` 不是用**你的**请求文件加密的，会提示：

```
❌ 挂载失败：包的接收密钥与本机不匹配，或文件损坏
```

**这是设计如此。** 每个加密包只对一台电脑的一个 Windows 账户有效。

### 每次都要重新加载

模型不是永久安装的，是**临时装载**。关掉软件就卸载了，下次用要再点一次"加载并挂载模型"。

好处是：不用的时候模型完全是加密状态，硬盘上没有明文。

## 四、⚠️ 什么情况会让你的模型失效

**你的钥匙绑定的是"这台电脑上的这个 Windows 账户"。** 以下操作会让它永久失效：

| 操作 | 后果 |
|---|---|
| 重装 Windows | **所有已购模型全部无法打开** |
| 换电脑 | 同上 |
| 换用另一个 Windows 账户登录 | 同上 |
| 删除或重置 Windows 用户账户 | 同上 |

**钥匙无法备份、无法导出、无法迁移。** 这是为了防止模型被复制传播 —— 代价就是换机器要重新走一遍流程。

**遇到这些情况怎么办：**

1. 重新安装本软件（如果是新电脑）
2. 点 **导出请求** 生成新的 `.vreq`
3. 发给画师，请画师**重新加密一份**发给你

> 所以：**打算重装系统前，先跟画师打个招呼。** 也建议你保留和画师的联系方式与购买记录。

## 五、常见问题

### 提示「未检测到 VTube Studio」

软件会自动查找 VTS（正在运行的进程、Steam 库、安装记录三种途径）。都找不到就会报这个。

**解决办法：先手动打开一次 VTube Studio，然后再点加载。**

界面上没有手动指定 VTS 路径的地方，所以如果你的 VTS 是绿色版或装在特殊位置，可能需要联系技术支持。

### 提示「无法挂载到 VTS 模型目录」

软件对 VTS 的安装目录没有写入权限。常见原因：

- VTS 装在 `C:\Program Files` 下面
- Windows 开了"受控文件夹访问"（防勒索软件功能）

**解决办法：** 试试右键 `VModelClient` → 以管理员身份运行。或者把 VTS 的"受控文件夹访问"例外加上。

### 提示「同名模型目录已存在」

VTS 的模型文件夹里已经有一个同名的文件夹了（比如你以前手动放过同款模型）。

**解决办法：** 去 VTS 的模型目录（`VTube Studio_Data\StreamingAssets\Live2DModels`）把那个同名文件夹改名或删掉。

### 提示「检测到逆向分析工具」

你电脑上正在运行 RenderDoc、Cheat Engine、NinjaRipper 之类的工具。这些工具能用来窃取模型，所以软件会拒绝加载。

**解决办法：** 关掉这些程序再试。

> **加载后再打开这些工具，模型会在十几秒内自动卸载。** 如果你因为工作需要用这类工具，请在不加载模型时使用。

### 提示「程序完整性校验失败」

程序文件被改动过。常见原因：

- 杀毒软件误改了程序文件
- 下载过程中文件损坏
- 只复制了 `VModelClient.exe` 而没有走安装包

**解决办法：重新下载安装包，完整安装一遍。** 不要单独复制 exe 文件到别处运行。

### 提示「Dokan 驱动未就绪」

驱动组件没装好。**重启一次电脑**通常就解决了。还不行就重新运行安装包。

### 指纹那串字看不全

那一栏显示不下 64 个字符，会被省略。**这不影响使用** —— 你不需要手抄它，导出的 `.vreq` 文件里就包含完整信息。

### 我在 VTS 里改的设置会保存吗

会。VTS 写回的配置（表情、快捷键、模型位置等）保存在 `.vkit` 文件**旁边**一个 `.cfgs` 结尾的文件夹里，加密包本身不会被改动。

> 所以**别把 `.vkit` 单独移动到别的文件夹** —— 那样配置会找不到。移动的话请把 `.cfgs` 文件夹一起带上。

## 六、隐私说明

- **本软件完全不联网。** 没有账号、没有激活服务器、没有使用统计。断网可以正常使用。
- 运行日志保存在 `%LOCALAPPDATA%\VVON\ModelClient\Logs\`，**不记录**任何密钥或模型内容。你可以随时打开查看。
- 软件不会读取你电脑上的其他文件，不会收集任何个人信息。

---

## 七、需要帮助时

请提供以下信息，方便定位问题：

1. 你看到的**完整提示文字**
2. Windows 版本（按 `Win + R`，输入 `winver` 回车，把看到的版本号抄下来）
3. 日志文件：把下面这行粘到文件资源管理器地址栏，回车后把 `vmodel_debug.log` 发过来

```
%LOCALAPPDATA%\VVON\ModelClient\Logs
```

4. 软件版本：点主界面**左下角的版权文字**，弹出的「关于」框里有
